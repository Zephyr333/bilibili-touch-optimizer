# bilibili-touch-optimizer

HTML5 视频触屏手势操作与 Bilibili 触屏体验优化 Userscript。

## 功能特性

- **HTML5 视频触屏手势**：
  - **纯净界面零侵入**：彻底移除所有悬浮功能按键与锁屏遮罩，还原本生全屏画面；保留居中 Toast、双击 Seek 动画指示与底部 2px 极细微缩进度条。
  - **滑动手势**：左侧 30% 上下滑动调节亮度（含 100% 原画亮度上下 10% 磁吸卡位与切档微震），右侧 30% 上下滑动调节音量，中间 40% 为垂直安全盲区。
  - **双指手势**：固定为双指缩放调节播放速度，每次调节量化为固定 0.25x 步进（每 36px 物理移动切档，附带 10ms 触感震动反馈，支持 0.25x ~ 4.0x）。
  - **单指长按**：默认以固定 3.0 倍速临时加速播放，松手恢复原速；若中途落下第二指自动无缝切换为双指调速。
  - **双击操作**：播放器左侧/右侧双击快退/快进（标准 10s 累加步进；跨半区连击严格隔离，先右双击后左双击必须在新半区落满 2 指才独立起算，杜绝误累加 20s；800ms 内快速换向即时清零对侧与重置累加），中区双击切换全屏（全对称状态机守卫，进出全屏无缝保持原播放与暂停状态，完播与报错即时卸载杜绝异常拉起）。
  - **屏幕防误触死区**：顶部 36px 窄条（下拉状态栏不误触手势且杜绝触发播放/暂停，高度比例自适应上限 15%），底部 100px 区域（操作进度条与播放控制不误触手势，高度比例自适应上限 35%）。
- **默认播放偏好**：
  - 播放所有视频时默认以 1.5 倍速播放（长按固定 3.0 倍速）。
  - B站播放器默认开启字幕、默认关闭弹幕。
  - 默认解除静音并拉满 100% 音量（支持交互手势绕过浏览器自动播放静音限制）。
- **B站专属触屏优化**：
  - 脚本生效作用域严格收敛限定至 B 站常规点播域（`bilibili.com`），通过元数据 `@exclude` 与入口断言彻底排除直播域名（`live.bilibili.com`），完全保留直播间原生互动与全屏逻辑，杜绝手势与缓冲冲突。
  - 触控操作窗口期内智能拦截长按弹出的原生右键菜单，避免干扰正常手势。
  - 全面杜绝控制栏文字误选高亮。
- **手机端高性能与低功耗架构**：
  - **Seek 寻道 40ms 节流**：滑动过程降频寻道并在抬手瞬间最终精准校准，彻底解决高码率/4K 视频横向滑动解码器卡顿掉帧。
  - **Toast 零回流渲染**：DOM 节点常驻缓存且采用 `textContent`，彻底消除滑动中的强制同步布局（Reflow）。
  - **微缩进度条 GPU 合成**：升级为 `transform: scaleX` 硬件加速绘制，CPU 零几何排版重排。
  - **解静音极速守卫**：音量就绪后以 0.0001ms 瞬时返回，彻底避免日常浏览点赞与翻评论时的 DOM 深度遍历与 JSON 解析。
  - **偏好轮询及早退出**：字幕、弹幕与音量全部就绪后立即终止定时器，消除开播前 4 秒无谓空转与重排。

## 安装方式

在 Tampermonkey 或 ScriptCat 中添加安装 `bilibili-touch-optimizer.user.js`。
