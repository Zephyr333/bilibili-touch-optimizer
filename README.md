# bilibili-touch-optimizer

HTML5 视频触屏手势操作与 Bilibili 触屏体验优化 Userscript。

## 功能特性

- **HTML5 视频触屏手势**：
  - **滑动手势**：左侧上下滑动调节亮度，右侧上下滑动调节音量，水平滑动调节进度。
  - **双指手势**：支持双指捏合缩放（画面放大与平移）或双指变速两种模式切换。
  - **单指长按**：默认以固定 3.0 倍速临时加速播放，松手恢复原速。
  - **双击操作**：播放器左侧/右侧双击快进快退（支持按秒/按帧累加），中区双击切换全屏（全对称状态机守卫，进出全屏无缝保持原播放与暂停状态）。
  - **屏幕防误触死区**：顶部 36px 窄条（下拉状态栏不误触手势），底部 100px 区域（操作进度条与播放控制不误触手势，高度比例自适应上限 35%）。
  - **画面与屏幕控制**：全屏下提供锁定手势按键、方向锁定按键，并将左上角原旋转按键改造为一键刷新页面。
  - **状态指示**：常驻迷你播放进度条与操作浮层反馈。
- **默认播放偏好**：
  - 播放所有视频时默认以 1.5 倍速播放（长按固定 3.0 倍速）。
  - B站播放器默认开启字幕、默认关闭弹幕。
  - 默认解除静音并拉满 100% 音量（支持交互手势绕过浏览器自动播放静音限制）。
- **B站触屏优化**：
  - 针对 B站网页播放器，在触控操作窗口期内智能拦截长按弹出的右键菜单，避免干扰正常手势。
- **通用播放器去杂质**：
  - 自动过滤常见 HTML5 播放器（DPlayer、Artplayer、MacPlayer 等）的暂停广告层。

## 安装方式

在 Tampermonkey 或 ScriptCat 中添加安装 `HTML5视频手势 x Bilibili触屏优化.user.js`。
