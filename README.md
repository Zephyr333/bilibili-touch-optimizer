# bilibili-touch-optimizer

HTML5 视频触屏手势操作与 Bilibili 触屏体验优化 Userscript。

## 功能特性

- **HTML5 视频触屏手势**：
  - **纯净界面零侵入**：彻底移除所有悬浮功能按键与锁屏遮罩，还原本生全屏画面；保留居中 Toast、双击 Seek 动画指示与底部 2px 极细微缩进度条。
  - **滑动手势**：左侧 30% 上下滑动调节亮度（含 100% 原画亮度上下 10% 磁吸卡位与切档微震），右侧 30% 上下滑动调节音量，中间 40% 为垂直安全盲区。
  - **双指手势**：固定为双指缩放调节播放速度，每次调节量化为固定 0.25x 步进（每 36px 物理移动切档，附带 10ms 触感震动反馈，支持 0.25x ~ 4.0x）。
  - **单指长按**：默认以固定 3.0 倍速临时加速播放，松手恢复原速；若中途落下第二指自动无缝切换为双指调速。
  - **双击操作**：播放器左侧/右侧双击快退/快进（标准 10s 累加步进），中区双击切换全屏（全对称状态机守卫，进出全屏无缝保持原播放与暂停状态）。
  - **屏幕防误触死区**：顶部 36px 窄条（下拉状态栏不误触手势），底部 100px 区域（操作进度条与播放控制不误触手势，高度比例自适应上限 35%）。
- **默认播放偏好**：
  - 播放所有视频时默认以 1.5 倍速播放（长按固定 3.0 倍速）。
  - B站播放器默认开启字幕、默认关闭弹幕。
  - 默认解除静音并拉满 100% 音量（支持交互手势绕过浏览器自动播放静音限制）。
- **B站专属触屏优化**：
  - 脚本生效作用域严格收敛限定至 B 站（`bilibili.com`）。
  - 触控操作窗口期内智能拦截长按弹出的原生右键菜单，避免干扰正常手势。
  - 全面杜绝控制栏文字误选高亮。

## 安装方式

在 Tampermonkey 或 ScriptCat 中添加安装 `bilibili-touch-optimizer.user.js`。
